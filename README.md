# 프리코스 3주차 - 로또
## 1. 프로젝트 개요
> 로또를 뽑고 몇 개가 당첨됐는지, 수익률은 얼마인지 출력
## 2. 기능 목록
### 1. 로또 구매 금액 입력
- [x] 1000원 단위인지 검증
- [x] 문자가 아닌 숫자인지 검증
### 2. 당첨 번호 입력
- [x] 쉼표로만 구분되는지 검증
- [x] **1~45** 범위의 숫자인지 확인
### 3. 로또 기계에서 번호 생성
- [x] (로또 구매 금액 / 1000)개의 로또 뽑기
- [x] 한 개의 로또 당 6개의 숫자 뽑기
- [x] 각 숫자가 **1~45** 범위에 있는지 확인
- [x] 생성한 숫자가 중복되지 않는지 확인
### 4. 당첨 번호와 생성 번호 대조
- [x] 각 등수 조건에 맞는 금액 반환

    |등수|조건|금액|
    |---|---|---|
    |1등|6개 번호 일치|2,000,000,000원|
    |2등|5개 번호 + 보너스 번호 일치|30,000,000원|
    |3등|5개 번호 일치|1,500,000원|
    |4등|4개 번호 일치|50,000원|
    |5등|3개 번호 일치|5,000원|
### 5. 당첨 내역 출력
- [x] 각 등수에 몇 개가 당첨됐는지

+ 3개 일치 (5,000원) - 0개
+ 4개 일치 (50,000원) - 0개
+ 5개 일치 (1,500,000원) - 0개
+ 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
+ 6개 일치 (2,000,000,000원) - 0개
### 6. 수익률 출력
- [x] (총 당첨 금액) / (로또 구매 금액) * 100

+ 총 수익률은 00%입니다.

## 4. 프로젝트 구조
### **domain**

| 클래스명 | 역할 |
|---|---|
| `Lotto` | 생성 번호 저장. 당첨 번호와 생성 번호 대조 |
| `LottoGenerator` | 로또 기계에서 로또 번호 생성 |
| `Rank` | 등수와 상금에 대한 enum |
| `RankCalculator` | 수익률 생성 |
| `WinningStatisics` | 각 등수에 몇 개가 당첨됐는지, 수익률은 얼만지 계산 |

### **service**

| 클래스명| 역할 |
|---|---|
|`LottoMachine`| 로또 발매기에서 로또 뽑고, 통계 계산 |

### **error**

| 클래스명 | 역할 |
|---|---|
| `ErrorMessages` | 에러 메시지 모음 |

### **validator**

| 클래스명 | 역할 |
|---|---|
| `InputNNumberValidator` | 1. 로또 구매 금액 검증<br>2. 입력받은 당첨 번호 형식 검증<br>3. 보너스 번호 검증 |

### **view**

| 클래스명 | 역할 |
|---|---|
| `InputNumbers` | 사용자로부터 구매 금액, 당첨 번호, 보너스 번호 입력받음 |
| `OutputStatistics` | 발행한 로또 내의 번호, 당첨 개수, 수익률 출력 |


### **controller**

| 클래스명 | 역할 |
|---|---|
| `LottoController` | 로또 발행 전체 흐름 관장 |
